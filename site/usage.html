Uso y capacidades actuales

Qué hace hoy la aplicación

Personal Tax Ledger es hoy un estimador y ledger tributario personal local-first para Chile. La aplicación organiza información anual, calcula efectos tributarios explicables y mantiene los datos localmente en SQLite.

Estado actual, no roadmap. Esta página describe capacidades ya presentes en el producto. Lo futuro se marca explícitamente como pendiente.

Cómo se usa en Windows

1. Instalar

Ejecutar PersonalTaxLedger-Setup.exe. El usuario final no necesita Git, Node.js, npm, WSL, Mono ni Wine.

2. Abrir la aplicación

Electron inicia el runtime local y abre la interfaz React. El servicio HTTP interno usa un puerto efímero, sin configuración manual.

3. Registrar y revisar información

Usar los módulos de Ingresos, Boletas, Hipotecario y Configuración; revisar el resultado consolidado en Resumen y comparar alternativas en Escenarios.

4. Cerrar y volver a abrir

Los datos permanecen en SQLite bajo el perfil userData de Electron y sobreviven al cierre, reinstalación y desinstalación/reinstalación observadas.

Limitaciones deliberadas del estado actual

  • no existe todavía firma de código ni reputación SmartScreen gestionada;
  • no existe canal formal de auto-update;
  • backup/export/restore y migraciones de esquema aún no constituyen un contrato de producto cerrado;
  • el UAT con usuario no técnico sigue siendo el siguiente gate de experiencia;
  • la distribución Linux todavía no está implementada ni validada.

Fuente funcional: navegación y módulos actuales de apps/local/web/src/features, contratos del core y documentación de estado del repositorio.
