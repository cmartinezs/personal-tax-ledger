Experimentos negativos controlados

RECHAZADO

Packager prune=true

Eliminó paquetes internos materializados y produjo ERR_MODULE_NOT_FOUND. Decisión final: pruning especializado propio.

CORREGIDO

Squirrel sin aliases 7-Zip

CreateZipFromDirectory falló hasta materializar explícitamente 7z.exe/7z.dll desde la variante del host.

NO REQUERIDO

allowScripts para electron-winstaller

El clean install bloqueó su install script y aun así PTL generó el instalador correctamente mediante su preflight determinista.
