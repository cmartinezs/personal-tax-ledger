# Errores preexistentes de `tsc -b` en web

**Tipo**: técnico

**Descripción**: La compilación de TypeScript falla por tres problemas preexistentes: incompatibilidad de tipos en `App.tsx`, falta de declaraciones para la importación lateral de `styles.css` y una configuración incompatible de `allowImportingTsExtensions` en `tsconfig.node.json`.

**Impacto**: `tsc -b` no puede usarse como verificación limpia del frontend, aunque `vite build` sí finaliza correctamente. Hallazgo adicional (2026-08-06, pack-a5-fix prompt 07): el script raíz `npm run build` invocaba `tsc -b && vite build` dentro de `web/package.json`, por lo que `npm run build` y, por extensión, el paso `- run: npm run build` de CI estaban rotos desde que se agregó ese paso (commit `786073c`), aunque nadie lo notó porque la verificación documentada en `AGENTS.md` usa `cd web && npx --no-install vite build`, que nunca pasa por `tsc -b`. Se corrigió separando los scripts de `web/package.json` en `"build": "vite build"` y `"typecheck": "tsc -b"`, y CI ahora corre el typecheck en modo informativo (`continue-on-error: true`) hasta que este gap se resuelva.

**Acción requerida**: Ajustar los tipos de configuración, agregar la declaración de assets CSS y corregir la configuración de TypeScript/Vite en una tarea separada.

**Prioridad**: media
