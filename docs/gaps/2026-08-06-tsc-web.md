# Errores preexistentes de `tsc -b` en web

**Tipo**: técnico

**Descripción**: La compilación de TypeScript fallaba por tres problemas preexistentes: incompatibilidad de tipos en `App.tsx`, falta de declaraciones para la importación lateral de `styles.css` y una configuración incompatible de `allowImportingTsExtensions` en `tsconfig.node.json`. Estos problemas fueron resueltos durante Pack A.12.

**Impacto**: Resuelto. `tsc -b` pasa correctamente y CI lo ejecuta como check bloqueante.

**Acción requerida**: Ninguna; mantener `npm run typecheck` en CI.

**Prioridad**: baja
