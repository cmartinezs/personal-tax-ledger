# Fuente de shared-ui

Componentes React presentacionales. Reciben datos, formatos y callbacks por props; no realizan fetch, acceden a SQLite, leen env ni contienen URLs de despliegue.

Después de modificar esta carpeta, ejecutar el build del workspace y actualizar `dist/` versionado. Revisa [`../README.md`](../README.md) y [`../test/README.md`](../test/README.md).
